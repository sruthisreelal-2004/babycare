Baby Care Mnagement System

The BabyCare Management System is a web application designed to simplify and improve childcare service management. It connects parents with babysitters, doctors, nutritionists, and daycare services in a centralized platform.

🚀 Features

👨‍👩‍👧 Parent Module:

Register and login|
Add baby details|
Request babysitter/doctor/nutritionist|
View services and feedback|
Make payments

👶 Baby Management:

Baby enrollment|
Baby health records|
Vaccination tracking|
Attendance monitoring

🧑‍⚕️ Service Providers:

Babysitter management|
Doctor management|
Nutritionist management|
Service approval/rejection

🏢 Admin / Daycare:

Manage users|
Manage services|
Track requests|
Monitor attendance|
Handle payments
